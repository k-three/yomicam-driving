# よみキャン 送迎記録

読谷村の放課後キャンパスで、送迎の記録と月次報告を行うためのウェブアプリ。

- **アプリ本体と手順書 … [`app/`](app/) を参照**
- 運転手用 … 出発・学校到着・乗車人数・拠点到着をタップで記録
- 管理者用 … 運行状況の把握、記録の修正、月次帳票（輸送記録・アルコールチェック記録簿）の作成

## 経緯

もとは Google スプレッドシートに紐づく Apps Script として作っていたが、
電波の弱い車内での取りこぼし、起動の遅さ、印刷体裁を指定できないことから、
ウェブアプリ（Firestore + GitHub Pages）へ移行した。
Apps Script 版は本番運用に入る前に役目を終えたため、このリポジトリからは削除している。

## このリポジトリに置かないもの

- **個人名**（職員・児童とも）… 運転者と車両の一覧は管理画面の「設定」から登録し、
  Firestore に保存する。コードには置かない。
- **パスワード** … Firebase Authentication 側に保管する。
- **運行の実データ** … すべて Firestore にある。
